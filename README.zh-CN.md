# Minecraft 客户端源码归档

这是一个个人收集的 Minecraft 客户端源码、脚本、模块及相关文件归档，主要收集时间为 2020–2022 年。

[English Version](README.md)

本仓库仅用于学习、历史记录和软件分析。仓库中的项目已经过时且不再维护，基本不适用于当前版本的 Minecraft，也不应被视为能够影响现代反作弊系统的工具。

## 目录说明

- `src/` — 收集的客户端源码压缩包
- `java/` — Java/Kotlin 源码或模块
- `js/` — JavaScript 脚本及相关文件
- `jar/` — 已编译的客户端、模组和工具

其中可能包含重复文件、不完整项目、修改版或破解版本、测试构建、分卷压缩包，以及来源不明确的文件。

## 历史背景

大部分内容收集于 2020–2022 年，反映的是当时 Minecraft 客户端修改和反作弊环境。

这些项目已经远远过时，不应被视为当前可用、受支持、适合生产环境，或能够有效对抗现代反作弊系统的软件。
