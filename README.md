# Minecraft Client Source Archive

A personal archive of Minecraft client source code, scripts, modules, and related files collected between 2020 and 2022.

[简体中文](README.zh-CN.md)

This repository is preserved for educational, historical, and software-analysis purposes. The projects in this collection are old, unmaintained, and largely irrelevant to modern Minecraft versions and anti-cheat systems.

## Archive Contents

- `src/` — Collected client source archives
- `java/` — Java and Kotlin source files or modules
- `js/` — JavaScript scripts and related files
- `jar/` — Compiled clients, mods, and utilities

The collection may contain duplicate files, incomplete projects, modified or cracked distributions, test builds, split archive parts, and files with unclear provenance.

## Historical Context

Most of the material was collected during 2020–2022. It reflects the Minecraft client-modification and anti-cheat landscape of that period.

These projects should not be considered current, supported, production-ready, or effective against modern anti-cheat systems.
